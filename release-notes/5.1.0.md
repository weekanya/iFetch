# iFetch 5.1.0

## English

- Added a dedicated RootHide package for `iphoneos-arm64e`.
- Added runtime `jbroot` path resolution in the app, CLI, helper, diagnostics, and Control Center module.
- Added the application and data-container entitlements required by RootHide.
- GitHub Releases and the Sileo repository now publish both conventional rootless and RootHide packages.
- Conventional rootless support remains available for iOS 14–17.

Sileo automatically selects the package supported by the active jailbreak environment.

- Rootless file: `com.wee1ka.ifetch_5.1.0_rootless_iphoneos-arm64.deb`
- RootHide file: `com.wee1ka.ifetch_5.1.0_roothide_iphoneos-arm64e.deb`

## Русский

- Добавлен отдельный пакет RootHide для `iphoneos-arm64e`.
- В приложение, CLI, helper, диагностику и модуль Control Center добавлено определение пути `jbroot` во время работы.
- Добавлены права доступа к приложениям и контейнерам данных, необходимые RootHide.
- GitHub Releases и Sileo-репозиторий теперь публикуют пакеты для обычного rootless и RootHide.
- Поддержка обычных rootless-джейлбрейков на iOS 14–17 сохранена.

Sileo автоматически выберет пакет для активного jailbreak-окружения.

- Rootless: `com.wee1ka.ifetch_5.1.0_rootless_iphoneos-arm64.deb`
- RootHide: `com.wee1ka.ifetch_5.1.0_roothide_iphoneos-arm64e.deb`
