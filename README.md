# iFetch 📱

**iFetch** — нативный системный монитор и мощный набор утилит для iOS 15.0 – 16.7.x (Dopamine / Rootless).

Интерфейс спроектирован строго по гайдлайнам **Apple Human Interface Guidelines (HIG)** в стиле классического приложения «Настройки». Никаких лишних элементов — только чистая типографика, системные цвета и прямой доступ к аппаратному обеспечению.

---

## ✨ Основные возможности

* **Нативный дизайн Apple:** Полное соответствие системному UI iOS (динамическая тёмная/светлая тема, классические таблицы Настроек).
* **Обход Sandbox (Direct IOKit Access):** Чтение точного количества циклов перезарядки аккумулятора напрямую из ядра (`AppleSmartBattery`).
* **Мониторинг ресурсов:**
  * Занятая и свободная оперативная память в реальном времени.
  * Точное состояние накопителя.
  * Время работы системы (Uptime) и количество установленных пакетов APT.
  * Счётчик активных `.dylib` твиков.
* **Информация о железе и сети:**
  * Архитектура процессора (`arm64e`), версия ядра Darwin, термостатус (Thermal State).
  * Локальный IP-адрес Wi-Fi (`en0`) и статус заряда аккумулятора.
* **Системные утилиты:**
  * Быстрый **Respring** (`sbreload`).
  * Сброс кэша иконок **UICache** (`uicache -a -r`).
  * Принудительный вход в **Safe Mode**.
  * Глубокая перезагрузка окружения **Userspace Reboot** (`launchctl`).

## 📦 Установка

1. Перейдите в раздел **Releases** в этом репозитории и скачайте последнюю версию файла `.deb`.
2. Откройте скачанный файл через **Filza File Manager** или **Sileo**.
3. Нажмите «Установить» (Install).
4. Приложение появится на домашнем экране (если иконка не появилась, используйте кнопку UICache внутри утилит или через TrollStore).
