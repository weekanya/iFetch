# iFetch

Привет! Это **iFetch** — системный монитор и панель утилит, которую я запилил под rootless-джейлбрейк Dopamine (iOS 15–16). 

Данный твик сделан под чистый интерфейс, один в один как родные Настройки, системные цвета и полная схожесть с UI от Apple

## Как это устроено и что умеет

- **Прямой доступ к ядру (Sandbox Bypass):** iOS жёстко прячет реальное состояние железа от стороннегофта. Я прописал специальные права (Entitlements) и зацепился напрямую за аппаратный фреймворк `IOKit`. Благодаря этому iFetch читает точные циклы заряда аккумулятора (`AppleSmartBattery`) без каких-либо костылей и ограничений песочницы.
- **Точные метрики в реальном времени:** 
  - Динамический опрос занятой и свободной памяти через `mach_host_self()`.
  - Мониторинг заполнения накопителя.
  - Точный аптайм системы (сколько устройство работает с последней загрузки).
  - Архитектура процессора (`arm64e`), версия ядра Darwin и текущий термостатус устройства.
- **Интеграция с джейлбрейком:** Твик умеет сканировать корневую систему: считает общее количество пакетов, установленных через APT, и выводит список активных `.dylib` библиотек (активных твиков) в папке `/var/jb/Library/MobileSubstrate/DynamicLibraries`.
- **Низкоуровневые утилиты:** Никаких долгих поисков в терминале. Прямо из интерфейса можно дернуть системные демоны:
  - **Respring** (`sbreload`)
  - **UICache** (сброс кэша иконок)
  - **Safe Mode** (принудительный безопасный режим через перехват `SEGV`)
  - **Userspace Reboot** (глубокая перезагрузка пользовательского пространства без потери джейлбрейка)

## Технические детали
Твик написан на Objective-C с использованием нативных UIKit-компонентов. Сборка идет через Theos под современную rootless-архитектуру с включенным ARC (Automatic Reference Counting), что полностью исключает утечки памяти.
