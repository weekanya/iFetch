# iFetch 5.0.0

## English

- Rebuilt the application lifecycle, navigation, diagnostics, tools, and settings in Swift.
- Migrated the Control Center module to Swift.
- Added an iOS 18-inspired visual style with updated materials, typography, cards, charts, and SF Symbols.
- Fixed icon colors changing after switching the application language.
- Kept the low-level diagnostics engine, CLI, WidgetKit metrics, and privileged helper native for reliability.

Rootless jailbreaks on iOS 14–17 are supported.

## Русский

- Жизненный цикл приложения, навигация, диагностика, инструменты и настройки переписаны на Swift.
- Модуль Control Center перенесён на Swift.
- Добавлен визуальный стиль в духе iOS 18 с обновлёнными материалами, типографикой, карточками, графиками и SF Symbols.
- Исправлено изменение цветов иконок после переключения языка.
- Низкоуровневая диагностика, CLI, метрики WidgetKit и привилегированный helper оставлены нативными ради надёжности.

Поддерживаются rootless-джейлбрейки на iOS 14–17.
