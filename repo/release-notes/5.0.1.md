# iFetch 5.0.1

## English

- Restored the missing Advanced Diagnostics icon.
- Added stable colored icons and a fallback for every diagnostics menu item.
- Updated the Advanced Diagnostics title to display the current iFetch version.

Rootless jailbreaks on iOS 14–17 are supported.

## Русский

- Восстановлена отсутствующая иконка «Расширенной диагностики».
- Добавлены стабильные цветные иконки и резервная иконка для каждого пункта диагностики.
- Заголовок расширенной диагностики теперь показывает текущую версию iFetch.

Поддерживаются rootless-джейлбрейки на iOS 14–17.
