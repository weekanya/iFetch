# iFetch 6.0.0

## English

### Hardware Speaker Diagnostics
- Dedicated testing for Top (Earpiece), Bottom (Main), and Stereo output.
- Hardware-level discrete channel routing via `AVAudioSession` in `mode: .measurement` for 100% channel isolation without DSP cross-talk.
- Integrated tone frequency generator: Bass (250 Hz), Mid/A4 (440 Hz), Calibration (1 kHz), Treble (4 kHz), and Frequency Sweep (200 Hz – 8 kHz).
- Instant, zero-latency channel and frequency switching on the fly without audio drops or stutter.
- Quick channel inversion toggle (`Swap Channels`).
- 60/120 FPS GPU-accelerated equalizer spectrum and speaker glow visualizer with Haptic Feedback.

### Jetsam Memory & Priority Explorer
- Real-time memory limit sampling via Darwin kernel `memorystatus_control`.
- Categorization into priority bands (Foreground, Background, Daemons, System) with kill risk estimation.
- 3-way process sorting filter `[ CPU | RAM | Jetsam ]` and detailed process inspection cards.

### Thermal State & Hardware Throttling
- Real-time SoC thermal state monitoring (Nominal, Fair, Serious, Critical).
- Thermal throttling status and warnings integrated into Battery Diagnostics, Health Checklist, and CLI fetch.

### Public IP & Network Details Enhancements
- Added dedicated Public IP row in Network Details alongside local IPv4 and IPv6.
- One-tap quick copy to clipboard with haptic confirmation for all network parameters.
- Replaced blocking 14-second probe with non-blocking 1.5-second asynchronous lookup.

### One-Click System Diagnostics Report Exporter
- Export comprehensive diagnostics reports in formatted Markdown and structured JSON.
- Share via standard iOS Share Sheet directly from the Diagnostics menu or via the CLI flag (`ifetch --report`).

### Performance & Fast Loading
- Added in-memory TTL caching for dpkg package records, dylib mapping, and crash logs.
- Reduced disk I/O on screen transitions by over 95% for instant navigation.

Packages:

- Rootless: `com.wee1ka.ifetch_6.0.0_rootless_iphoneos-arm64.deb`
- RootHide: `com.wee1ka.ifetch_6.0.0_roothide_iphoneos-arm64e.deb`

## Русский

### Аппаратная диагностика динамиков
- Раздельная проверка верхнего (разговорного), нижнего (основного) и стерео-звучания.
- Аппаратная калибровочная маршрутизация `AVAudioSession` в режиме `mode: .measurement` для 100% изоляции каналов без фазовых искажений и взаимного проникновения сигнала.
- Встроенный генератор частотных тонов: Бас (250 Гц), Средние / Нота Ля (440 Гц), Калибровка (1 кГц), Высокие (4 кГц) и Частотный свип (200 Гц – 8 кГц).
- Мгновенное переключение каналов и частот на лету с нулевой задержкой без прерывания звукового потока.
- Быстрая инверсия каналов (`Поменять каналы местами`).
- Плавная 60/120 FPS GPU-анимация эквалайзера и подсветки активных динамиков с тактильным виброоткликом.

### Диспетчер лимитов памяти Jetsam
- Опрос лимитов памяти в реальном времени через системный вызов ядра Darwin `memorystatus_control`.
- Классификация по полосам приоритета Jetsam (Foreground, Background, Daemons, System) с оценкой риска выгрузки.
- Трёхпозиционный фильтр диспетчера процессов `[ CPU | RAM | Jetsam ]` и подробная карточка процесса.

### Термальное состояние и аппаратный троттлинг
- Мониторинг термального статуса процессора (Nominal, Fair, Serious, Critical).
- Отображение статуса троттлинга в диагностике батареи, чеклисте здоровья системы и консольном выводе CLI.

### Внешний IP и улучшения сетевых деталей
- Добавлена отдельная строка с внешним (публичным) IP в экране «Сетевые детали» рядом с локальными IPv4 и IPv6.
- Быстрое копирование любого сетевого параметра в буфер обмена в один тап с виброоткликом.
- Устранена 14-секундная блокировка интерфейса — сетевая проба переведена на быстрый асинхронный запрос (1.5 с).

### Экспорт системного отчёта в один клик
- Формирование полного отчёта системной диагностики в форматах Markdown и JSON.
- Удобная отправка через системное меню `Share Sheet` из раздела диагностики или через консоль (`ifetch --report`).

### Высокая производительность и мгновенное открытие
- Добавлено оперативное TTL-кэширование для статуса пакетов dpkg, маппинга dylib и логов падений.
- Нагрузка на диск при переключении экранов снижена более чем на 95% для мгновенного отклика интерфейса.
