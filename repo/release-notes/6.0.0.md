# iFetch 6.0.0

## English

- Added Hardware Speaker Diagnostics (Top Earpiece, Bottom Speaker, Stereo) with tone frequency generator (250 Hz, 440 Hz, 1 kHz, 4 kHz, Frequency Sweep) and discrete measurement audio routing.
- Added Jetsam Memory & Priority Explorer with real-time `memorystatus_control` sampling, memory limits, and kill risk analysis.
- Added SoC Thermal State & Hardware Throttling monitoring across the app, battery diagnostics, and CLI.
- Added One-Click Full System Diagnostics Report export in Markdown/JSON for sharing with developers.
- Added 60/120 FPS GPU-accelerated equalizer animations and Haptic Feedback.
- Added `--report` flag to `ifetch` command-line tool.

Packages:

- Rootless: `com.wee1ka.ifetch_6.0.0_rootless_iphoneos-arm64.deb`
- RootHide: `com.wee1ka.ifetch_6.0.0_roothide_iphoneos-arm64e.deb`

## Русский

- Добавлена аппаратная диагностика динамиков (верхний разговорный, нижний, стерео) с генератором частот (250 Гц, 440 Гц, 1 кГц, 4 кГц, Свип) и дискретной маршрутизацией.
- Добавлен диспетчер лимитов памяти Jetsam и полос приоритетов через `memorystatus_control` ядра Darwin.
- Добавлен мониторинг термального состояния SoC и аппаратного троттлинга.
- Добавлен экспорт полного системного отчёта диагностики в Markdown/JSON в один клик.
- Добавлены плавные 60/120 FPS GPU-анимации эквалайзера и тактильный виброотклик.
- Добавлен флаг `--report` для консольной утилиты `ifetch`.
